## What was built
Resolved all PHPCS/WordPress coding standards violations and additional WordPress.org review issues flagged across multiple plugin files. Fixes cover input sanitization, HPOS-compatible order queries, nonce security, Yoda conditions, boolean operator precedence, inline comment formatting, missing class doc comments, SVG inline style removal, and README External Services documentation.

## How it works
Each fix is a standards-compliance or security improvement with no change to plugin business logic:

- **Input sanitization**: Replaced `$_GET['page']` with `filter_input(INPUT_GET, 'page', FILTER_SANITIZE_FULL_SPECIAL_CHARS)` across onboarding steps and main plugin file.
- **Nonce security**: Added `wp_create_nonce()` to localized script data and `wp_verify_nonce()` check in the add-to-cart handler; appended nonce to the cart URL in JS.
- **HPOS compatibility**: Replaced deprecated `meta_key`/`meta_value` arguments in all `wc_get_orders()` calls with post-query `array_filter()` + `get_meta()`, making the plugin compatible with WooCommerce High-Performance Order Storage.
- **Raw SQL removal**: Replaced `$wpdb->get_col("SELECT blog_id FROM $wpdb->blogs")` with the `get_sites()` API in the activator.
- **Deactivator cleanup**: Removed the license deactivation API call; replaced with a single `delete_option()`.
- **Inline SVG styles**: Moved `.cls-1{fill:#1e1e1e;}` from inline SVG `<style>` blocks to `admin/css/mwb-admin-global-custom.css`.
- **PHP inline CSS → JS**: Moved `#edit-slug-box`/`#view-post-btn`/`.post-preview` hide styles from PHP `echo '<style>'` to `admin/js/mwb-admin-global-custom.js`.
- **Script enqueue fix**: Updated `wp_register_script()` and `wp_enqueue_script()` calls to use array syntax, plugin version constant, and correct in-footer flag.
- **My Bookings tab**: Unified order fetching to always use `wc_get_orders()`, removing the `OrderUtil` legacy `get_posts()` branch.
- **Global calendar fix**: Corrected hourly booking date/time parsing — extracts date and time-range separately before recombining into proper start/end timestamps.
- **README External Services**: Expanded section to document every third-party service endpoint, data sent, and when it is called, per WordPress.org requirements.
- **Earlier fixes** (PHPCS round 1): Unsanitized `$_GET`/`$_POST`/`$_SESSION` variables, `wp_unslash()`, Yoda conditions, boolean precedence, inline comment punctuation, missing class PHPDoc comments.
