## What was built
Resolved all PHPCS/WordPress coding standards violations flagged across multiple plugin files. Fixes cover input sanitization, Yoda conditions, boolean operator precedence, inline comment formatting, and missing class doc comments.

## How it works
Each fix is a standards-compliance correction with no change to plugin logic or behaviour:
- Unsanitized `$_GET`, `$_POST`, and `$_SESSION` variables were wrapped with the appropriate sanitization functions (`sanitize_text_field`, `absint`, `wp_unslash`).
- Yoda conditions were flipped to put the constant/literal on the left-hand side.
- Boolean expressions mixing `&&` and `||` were wrapped in explicit parentheses to clarify precedence.
- Inline comments that lacked a terminating `.` were updated.
- Two classes missing PHPDoc block comments had them added.
